# 点域 · 空间模型

一个独立的黑色单页首页，汇集之前的七个模型和新做的三个农业模型。当前目录仍为 pointfield-farm，复制进来的模型代码和依赖均在此项目内，运行时不依赖原 radar-scan-recreation 目录。

十个场景：农场全景、水塔水量、大棚状态、矿坑、储罐、港口、柱阵、天文台、空间站、海上风电。桌面在一屏内显示左侧介绍及指标、右侧三维模型及构成图、底部统一切换栏。手机上下排列，底部可横向滑动，当前选择在切换和改变尺寸后保持可见。没有其他页面或页尾。

双击 点域-全场景-双击打开.html 即可离线打开全部模型。仓库附带完整离线网页，无需安装依赖即可打开。

每个场景有 180,000 颗粒子。切换时约 1.85 秒重组，连续点选会从当前坐标继续变形。风电场的叶片独立旋转、海面轻微起伏，切出时保留当前姿态；暂停会冻结模型动画。农场保留全景、梯田、农舍、果园四个相机预设，可用拖拽打断镜头移动。

农场与多数旧场景使用金黄色体积扫描和偏白结构粒子，原有铜色建筑与蓝色太阳能板保留。柱阵保留循环向下的水平扫描面。水塔和大棚采用一次由上向下的扫描，扫过后显现粒子和数据，完成时保持结果，点击重新扫描可再运行。

水塔模型含九座不同高度的储水设施。内部蓝色水柱和圆环弧长对应各塔的示例水量，低水位用橙色表示。大棚含三座有通风窗、风扇、传感器与种植床的温室，配棚架示意图及温度、空气湿度、土壤含水和通风开度。示例数据在 src/operations.js 定义，未连接真实传感器。

新增场景的侧栏展示模型部件与图形；数量按程序生成的部件定义填写，属于视觉模型说明。所有模型均为程序生成，并非工程精度模型。

拖拽旋转、滚轮或双指缩放。空格暂停，C 打开参数，H 隐藏界面；画布获得焦点后加减键缩放。默认固定观察角度，可在参数中开启缓慢旋转。系统减少动态效果时默认暂停，切换立即展示完整模型，农业状态即时出现。

```

```

验证脚本使用工作区现有的 Chromium 路径；其他机器需修改 executablePath。

- src/farm.js：有高度场的丘陵梯田、果园、农舍、谷仓与附属设施。
- src/operations.js：九座水塔、三座温室与演示数据。
- src/industrial.js：从原项目复制的七个场景及详细部件，保留风机和海面运动属性。
- src/scenes.js：统一十个模型的粒子缓冲及材质属性，接入原采样管线。
- src/main.js：渲染、连续重组、三类扫描、相机、导航与参数。
- src/shaders.js、src/beam.js：GPU 运动姿态、重组、深度预绘制、主粒子和辉光，以及有厚度的闭合扫描体。
- src/details.js、src/industrial-details.js：对应模型的三维标识和引线，按时间淡入淡出。
- src/graphics.js：农场、供水、温室图形及水位、环境状态。
- src/catalog.js：七个新增场景的介绍、构成图形和部件说明。
- index.html、src/style.css：黑色单页、场景主题色与响应式布局。
- verify-catalog.mjs：全十场景切换、手机导航、风机姿态连续性、扫描方式与离线检查。

引擎采用 Three.js（MIT）和 OrbitControls。页面和程序生成模型为本工作区的自有实现，没有外部模型资产或在线依赖。原项目仍独立保留。

界面字体使用 Noto Sans SC 的本地字形子集，名称为 Pointfield UI，保留 400–600 的可变字重与等宽数字。字体由 Adobe / Google 提供，采用 SIL OFL 1.1；许可证在 licenses/NotoSansSC-OFL.txt。字体不是项目自创。src/typography.css 统一标题、正文、导航和读数的字体、字号及间距；离线文件内嵌字体和许可证。

增加新的中文文案后，可安装 Python fonttools、brotli，再运行 `python scripts/build-font.py <原始 Noto Sans SC 字体路径>` 更新字形子集。未收录字符自动使用系统中文字体。`node verify-typography.mjs` 检查十场景在桌面、紧凑桌面和手机的文字布局，以及离线字体加载。
